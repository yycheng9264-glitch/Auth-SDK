# 发布部署文档

## 1. 版本号规范

本项目遵循 [SemVer 语义化版本](https://semver.org/) 规范：

```
主版本号.次版本号.修订号
```

| 版本变动 | 说明 | 示例 |
|---------|------|------|
| **主版本** | 不兼容的 API 变更 | 1.0.0 → 2.0.0 |
| **次版本** | 向下兼容的功能新增 | 1.0.0 → 1.1.0 |
| **修订号** | 向下兼容的问题修复 | 1.0.0 → 1.0.1 |

开发阶段使用 0.x.x 版本。

## 2. 构建

```bash
# 安装依赖
npm install

# 构建所有格式（ESM + CJS + UMD）
npm run build
```

构建产物输出到 `dist/` 目录：

```
dist/
├── auth-sdk.esm.js          # ES Module（用于 import）
├── auth-sdk.esm.js.map
├── auth-sdk.cjs.js          # CommonJS（用于 require）
├── auth-sdk.cjs.js.map
├── auth-sdk.umd.js          # UMD（用于 <script> 标签）
├── auth-sdk.umd.js.map
└── types/
    └── index.d.ts           # TypeScript 类型声明
```

## 3. npm 发布

### 3.1 准备工作

确认 `package.json` 中的字段正确：

```json
{
  "name": "@team/auth-sdk",
  "version": "0.1.0",
  "main": "dist/auth-sdk.cjs.js",
  "module": "dist/auth-sdk.esm.js",
  "browser": "dist/auth-sdk.umd.js",
  "types": "dist/types/index.d.ts",
  "files": ["dist"],
  "private": false
}
```

### 3.2 发布流程

```bash
# 1. 更新版本号
# 手动修改 package.json 中的 version 字段，或使用：
# npm version patch  # 修订号 +1
# npm version minor  # 次版本号 +1
# npm version major  # 主版本号 +1

# 2. 构建
npm run build

# 3. 发布到 npm registry
npm publish --access public

# 4. 打 git tag（如果使用 git 管理）
# git tag v0.1.0
# git push origin v0.1.0
```

### 3.3 注意事项

- 发布前确认 `dist/` 目录已更新
- `.npmignore` 或 `package.json` 的 `files` 字段确保只发布 `dist/` 目录
- 如果发布到私有 npm registry，配置 `.npmrc`：
  ```
  @team:registry=https://your-private-registry.com/
  ```

## 4. CDN 部署

### 4.1 构建产物上传

将 `dist/auth-sdk.umd.js` 上传到 CDN 服务器。

推荐上传方式：

```bash
# 示例：使用阿里云 OSS
# ossutil cp dist/auth-sdk.umd.js oss://your-bucket/auth-sdk/0.1.0/auth-sdk.umd.js

# 示例：使用 AWS S3
# aws s3 cp dist/auth-sdk.umd.js s3://your-bucket/auth-sdk/0.1.0/auth-sdk.umd.js
```

### 4.2 版本管理策略

CDN 路径建议包含版本号，兼容方式：

```
# 带版本号（推荐，业务方锁定版本）
https://cdn.example.com/auth-sdk/0.1.0/auth-sdk.umd.js

# latest 别名（指向最新版本，方便测试）
https://cdn.example.com/auth-sdk/latest/auth-sdk.umd.js
```

### 4.3 CDN 使用

```html
<!-- 使用固定版本（推荐用于生产环境） -->
<script src="https://cdn.example.com/auth-sdk/0.1.0/auth-sdk.umd.js"></script>

<!-- 使用 latest（推荐用于开发测试） -->
<script src="https://cdn.example.com/auth-sdk/latest/auth-sdk.umd.js"></script>
```

## 5. 版本更新记录

每次发布时在 `CHANGELOG.md` 中记录变更：

```markdown
# 更新记录

## 0.1.0 (2025-01-15)

### 新增
- Web 模式鉴权（appId + appSecret 换取 token）
- 企微模式鉴权（OAuth 授权获取用户信息）
- 鉴权守卫功能（guard() 方法）
- 原生 UI 登录弹窗/全屏页
- 可选 fetch 封装（自动注入 token）
- npm ESM + CDN UMD 双模分发
```

## 6. 回滚方案

### npm 回滚

```bash
# 发布错误的版本时：
# 1. 先发布一个修复版本
npm version patch
npm publish

# 2. 或者废弃错误的版本（推荐，不影响已安装的用户）
npm deprecate @team/auth-sdk@0.1.0 "有严重问题，请使用 0.1.1"

# 3. 强制删除（不推荐，24 小时内可操作）
# npm unpublish @team/auth-sdk@0.1.0 --force
```

### CDN 回滚

- **固定版本路径**：修改业务方引用的版本号即可回滚
- **latest 路径**：重新上传旧版本文件到 latest 路径

## 7. 自动化发布

可以使用 GitHub Actions 或 GitLab CI 实现自动发布：

```yaml
# .github/workflows/publish.yml 示例
name: Publish

on:
  push:
    tags:
      - 'v*'

jobs:
  publish:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '18'
          registry-url: 'https://npm.pkg.github.com'
      - run: npm ci
      - run: npm run build
      - run: npm publish
        env:
          NODE_AUTH_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```
